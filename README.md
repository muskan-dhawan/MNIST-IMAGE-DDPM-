## 📖 Overview
This repository contains an implementation of a **Denoising Diffusion Probabilistic Model (DDPM)** to generate images based on the classic MNIST dataset. It demonstrates the fundamental concepts of diffusion models—a class of generative models that learn to synthesize data by iteratively denoising a normally distributed variable.

## ✨ Key Concepts Demonstrated
- **Forward Diffusion Process:** Adding Gaussian noise to MNIST images over a series of timesteps.
- **Reverse Denoising Process:** Training a neural network (typically a U-Net architecture) to predict and remove the noise.
- **Image Synthesis:** Sampling new, realistic handwritten digits from pure noise.
